# App Store privacy nutrition labels — answers

Apple asks this per data type. Use these exactly.

## Data used to track you
**None.** No advertising, no data brokers, no cross-app tracking. Answer "No" to the tracking question.

## Data linked to you

| Category | Type | Used for |
|---|---|---|
| Contact Info | Email address | App functionality, account management |
| Contact Info | Name | App functionality |
| User Content | Photos or videos | App functionality |
| User Content | Audio data | App functionality |
| User Content | Other user content (transcripts) | App functionality |
| Identifiers | User ID | App functionality |
| Usage Data | Product interaction | Analytics, app functionality |
| Purchases | Purchase history | App functionality |

## Data not linked to you

| Category | Type | Used for |
|---|---|---|
| Diagnostics | Crash data | App functionality |
| Diagnostics | Other diagnostic data | App functionality |

## Not collected — answer No to all of these
Location, health and fitness, financial info (card details go straight to Stripe, we never receive them), contacts, browsing history, search history, sensitive info, device ID for advertising.

## Third parties to declare
Supabase, Cloudflare, Deepgram, Modal, Stripe, Resend. All are processors acting on our instructions, not independent controllers.
